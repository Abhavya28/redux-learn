# Redux Learn

This repository is for learning and practicing **Redux and Redux Toolkit**.

---

## 📁 Included Folders

### 1. react-basics
Covers core Redux concepts:
- Store, actions, reducers
- Dispatch and state flow
- Redux Toolkit basics

📂 Folder: `redux-basics/`

---

### 2. shopping-cart
A mini Shopping Cart project built to practice Redux in a real use case.
- Add to cart
- Increase or decrease quantity
- Remove items
- Calculate total amount using global state

📂 Folder: `shopping-cart/`
